Repair hand–object contact in video.

When someone picks up a pan, their fingers should stay on the handle. A hand wiping the pan should be free to slide. When the person lets go, the reconstructed hand should leave too.

Two people prepare the evidence and the tools. Two train the models that decide when a hand touches and how its pose should change.

Choose your role

Foundation team

1. Video labeling

Watch the original clips and mark what each hand does to the target object. Keep near misses, hidden hands and disputed cases in the record. Ask the replay partner to label the pilot clips independently, then review disagreements together.

Hand over

A table of reviewed contact intervals, one example of each observed action, and a count of holds, slides and releases per object. The contact trainer uses these labels. The repair trainer uses the visible holds to find candidate examples.

2. Replay and measurement

Match each original frame to the saved 3D person, object and camera. Overlay them on the video, build a repeatable comparison view, and record where the starting reconstruction is visibly good or wrong.

Hand over

A clip list with frame IDs and data splits, a replayable starting result, and a score sheet. Use the same tool to export the before/after videos and independently score both models.

Model training team

3. Contact recognition

Train a small model that watches each hand with its target object. It estimates the chance of contact frame by frame. Add holding and sliding when there are enough reviewed examples of each.

Hand over

Saved weights, the confidence level used to turn a prediction on, and a file with the frame ID, hand, predicted state and confidence. Include example false touches and missed releases for the repair trainer.

4. Hand-pose repair and model lead

Build a simple repair with fixed rules, then train a model to correct small wrist and finger errors. Connect it to the contact predictions. Own the combined model version and the decision to adopt it.

Hand over

Repair weights, a command to run both models on one episode, corrected poses and a fallback to the original poses. Record which version passed or which failure still needs work, using the replay partner’s independent results.

Method · From video to repaired hands

1. Rebuild one clip everyone can inspect

Replay and measurement

Start with the foam block in EP16, original frames 90–209. Load the original video, the saved human pose and its matching MHR body decoder, the object mesh, its motion and the camera. For each frame, draw the 3D result over the image and save the frame ID. Check left and right hands, object size and camera alignment at the start, middle and end.

Ready to use when a teammate can reopen the 120-frame clip, switch the overlay on and off and see the same grip on the same frame. If the whole block is misplaced, check the camera, scale and object position before asking the model to move a finger. Find the input packages.

2. Mark what each hand actually does

Video labeling · Replay and measurement checks the labels

Use the four pilot windows covering 469 original frames. Write one row per hand for each continuous state. Record the episode, target object, person’s left or right hand, first and last original frame, touch state and action.

What you can seeWhat to record
Fingers stay at the same spot on the moving handle.Touching · holding

The hand reaches close, or hovers after letting go, with a visible gap.Clear of the target. These are important training examples.
A rim, cloth or another hand hides the contact.Cannot tell. If touch is visible but motion is unclear, mark only the action as uncertain.

Record the first visible touch and first clear separation. If the change is hidden, record its earliest and latest plausible frames. Two people label the pilot independently. Review disagreements against the video and keep unresolved intervals uncertain. Count separate actions per object so one long grip does not look like hundreds of examples.

3. See whether the right contact labels can fix a grip

Hand-pose repair with both foundation roles

Build a simple repair that can move a few wrist or finger joints within agreed limits. For a visible grip, pair a fingertip or palm with a nearby point on the object. During a hold, keep that point steady relative to the object as it moves. On a reliable mesh, gently push a finger back out if it crosses the surface. During a slide, allow movement along the surface. On release, turn off the pull toward the object. Keep a hidden or uncertain hand at its starting pose when there is too little evidence to change it.

Try the same repair with contact guidance off, with a simple distance rule, then with reviewed labels. Watch the same grip and release in all three. If even the reviewed labels cannot help, check the object surface, pose alignment and which joints can move. Continue to training once the team can show a visible, repeatable fix.

4. Train the contact model to read the video

Contact recognition

  1. Separate the objects. Group all three videos of each object together before making training examples. A starting split for ten objects is six for training, two for choosing settings and two for final testing. Keep pilot objects in development. Check earlier use of each group. Describe previously used test footage as a repeat check. Expand the reviewed labels across the groups.
  2. Teach one question first. Show about half a second of video around a frame, with the hand and target in view. Keep the existing image encoder fixed and train a small sequence model to predict touch. Include reaches that miss, first contact and release. Exclude uncertain answers from the training loss.
  3. Check mistakes on different objects. Compare predictions with reviewed labels on validation clips. Inspect missed touches and hands that stay marked as touching after release. Add hold versus slide only when both appear in enough distinct events to train and check. With only a touch prediction, use gentle surface contact and leave sideways motion free.
  4. Save the version. Choose weights and the confidence cutoff on validation clips. Export predictions for each hand and original frame. For repair training, generate training-clip predictions with a contact model that was trained on other objects.

5. Teach a second model how to move the hand

Hand-pose repair and model lead

  1. Make examples with a known correction. In training footage, select short sequences where the starting pose follows the visible hand and the contact looks plausible. Check both the image and the object surface. Add a small, known error to the wrist or a finger joint, such as curling fingers slightly into the block. Save the original sequence as the target. Include correct grips, slides and released hands with a target change of zero.
  2. Learn a small adjustment. Give the model the starting joint poses, nearby object surface, contact predictions and confidence across several frames. Ask it to undo the added error. Limit how far each joint can move, favor small changes that follow the visible hand, and keep the camera, object pose and body shape fixed. The training targets are reviewed reconstructions with known added errors. Real contact depth remains uncertain.
  3. Run both models on a real mistake. On validation video with natural errors, feed the first model’s predictions to the repair model. Overlay the result on the source and replay the approach, grip and release. Revert a proposed change if confidence or surface quality is too low, the image fit worsens beyond the agreed limit, or the correction exceeds its joint limit.

One complete output contains a repaired hand pose for each hand and frame, including the original pose wherever the repair was skipped. Save the skip reason and export through the existing reconstruction format. Reopen it and verify the same frame IDs and poses.

What counts as a pass?

Use the baseline and reviewer agreement to write down the minimum improvement and acceptable regressions before choosing a model. Choose settings on validation objects, then freeze both models, thresholds and repair limits. Run the selected pair once on the reserved objects and keep them out of tuning. Report each object and both hands, including skipped and failed cases.

  • Contact recognition. Count false touches and missed touches. Report the share of frames reviewers could judge and how many frames early or late each matched grasp or release was. Report unmatched events separately.
  • Hand repair. Measure the typical and worst depth inside reliable surfaces, the gap during touch, and unwanted movement along the object during a steady hold. Compare the hand overlay with the video. A wiping hand should still slide, and a released hand should stay free.
  • Evidence for a decision. Deliver the score table, matched source/before/after video for each pilot window, and the worst real failure. Verify every original frame survives export. The model lead adopts the learned repair only if it improves on the rule-based one within the agreed limits. Otherwise keep the better baseline and identify the failing component.

Risks and limitations

Hidden contact may stay ambiguous in a single view. A poor mesh can make a correctly placed hand look wrong. Start numerical depth checks on reliable surfaces such as the foam block. Check the hoop opening and pan cavity visually, and mark depth unavailable wherever the surface test cannot handle that shape. Local gap, depth and motion checks describe the reconstructed scene. Official geometry and acceleration scores require reference data unavailable in public Track 1.
