2026-10-03: Which final Track 1 requirements supersede the September notes? / 哪些最终要求取代旧说明？ Final requirements / 最终要求
The six final Track 1 requirements supplied on 2026-10-03 REPLACE all earlier conflicting Track 1 rules.
1. Fit one human-only Sim(3) from the first REFERENCE trajectory frame; apply it to humans and every object for the entire clip. Relative scale/placement errors and later drift remain.
2. Submit native MHR human trajectories, not SOMA-X parquet or per-frame human meshes.
3. Object Chamfer evaluates the POSED mesh in the shared WORLD frame after alignment. Shape and pose both count.
4. Acceleration error compares predicted and ground-truth SECOND temporal differences; it is not prediction-only smoothness. Over-smoothing can hurt.
5. Every object has a continuous pose on EVERY original frame, including occlusion and out-of-view.
6. Reconstruct all objects and estimate all parameters, including cameras, using Track 1 data only. NO Track 2 assets or derivatives, including iron/bowl/table/round-table meshes.

The first reference frame is the fixed rule, not an open choice between reference/scored frames. The native-MHR diagnostic scorer implements these semantics but does not certify official numerical equivalence. Real reconstruction and final official export still require implementation and validation. Static page text is pending republication where the editor is unavailable; use the linked authoritative requirements.

Shape, size, position and orientation errors therefore count. Do not recenter, independently align, or ICP-register each object before computing this metric.

How are submitted results aligned to the multi-view reference? Alignment
Final Track 1 requirement (2026-10-03): estimate ONE Sim(3), covering rotation, translation and scale, from the HUMAN POSE in the FIRST FRAME OF THE REFERENCE TRAJECTORY. Apply that exact transform to both the human and every object for the entire trajectory. Human and objects must already share a consistent frame and scale. Object placement/scale relative to the human and all drift after the first frame remain errors. A scored-frame subset must not choose a new alignment anchor.

最新要求：仅根据参考轨迹第一帧的人体姿态估计一次旋转、平移与尺度变换，同一个变换用于整段人体和全部物体。人和物必须共享坐标与尺度；相对人体的物体位置、大小错误，以及第一帧后的漂移均不会被自动修正。计分帧筛选不得改变对齐帧。此定义替代旧简略答案。

Is acceleration error measured against the reference, or on the submitted trajectory alone? Acceleration
Final Track 1 requirement (2026-10-03): acceleration error compares the SECOND-ORDER TEMPORAL DIFFERENCES of prediction with those of the ground truth. It measures agreement with real motion dynamics, not prediction-only smoothness. Over-smoothing can increase the error. The earlier September answer is replaced by this corrected requirement.

最新要求：加速度误差比较预测与真值的二阶时间差分，衡量真实动作变化是否一致；不是单独衡量预测是否平滑。过度平滑可能使成绩更差。此答案直接替代9月的旧定义。
